# Appliance manuals

Owner's manuals for appliances listed in `equipment/`. The recipe app does not open this folder. The equipment note points at the file.

- Emeril Lagasse Pressure AirFryer, 8 quart, model Y8D-AF-36: `emeril-lagasse-y8d-af-36.pdf`
  The manual covers Y6D-AF-36 (6 quart) and Y8D-AF-36 (8 quart). Saved from the owner's manual copy published for that model.
- Samsung over-the-range microwave ME21M706BAS: `samsung-me21m706bas.pdf`
  Samsung's user manual for ME21M706BA*, which includes this model. 2.1 cu. ft., 1000 W.
